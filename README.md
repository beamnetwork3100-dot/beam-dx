# Beam Dx

## Clinical Decision Support Platform for Laboratory Medicine

Beam Dx is an evidence-based web application that assists healthcare professionals with the interpretation of laboratory results.

## Vision

To improve laboratory reporting through standardized, evidence-based interpretation while supporting healthcare professionals in clinical decision-making.

## Version

0.1 Alpha

## Modules

- Full Blood Count (FBC)
- Liver Function Test (LFT)

## Technology Stack

Frontend:
- Next.js
- TypeScript
- Tailwind CSS

Backend:
- FastAPI

Database:
- PostgreSQL
